# dashboard_matrix

Two sibling AI-agent operations dashboards. Both are static (vanilla HTML/CSS/JS) — open `index.html` directly in a browser, no build step.

## v1-etsy-ultronos — Autonomous Store Command Center

Pixel-art factory-floor aesthetic for an autonomous Etsy/Printify store.
Themed around digital-product manufacturing: trend research, ideation, copy, image gen, listing forge, SEO, QA, publishing, customer comms, sales.

- **Brand:** ULTRONOS08 · STATION ONLINE · PRINTIFY · ETSY LIVE
- **Agents:** Astra · Vega · Nova · Pixel · Forge · Sage · Lumen · Atlas · Echo · Oracle
- **Missions:** Reach $2,000 revenue · Publish 5 listings · Get 50 sales · Generate 20 mockups · Respond to 15 messages · QA pass drafts
- **Visual:** purple / cyan / amber palette, pixel chibi agents, hex floors, factory equipment (radar dome, anvil, rocket pad, comm screens, etc.)

Open: `v1-etsy-ultronos/index.html`

## v2-claude-code-hub — AI Agent Operations Hub

Cleaner glassmorphic aesthetic for a Claude Code AI Command Center.
Themed around software development: research, plan, code, test, QA, deploy, voice agent, chatbot, analytics.

- **Brand:** AI Agent Operations Hub · Claude Code AI Command Center
- **Agents:** Research · Plan · Code · Test · QA · Deploy · Voice · Chatbot · Analytics
- **Missions:** Automate Code Review · Build AI Chat Assistant · Optimize CI/CD Pipeline
- **Visual:** cyan / electric-blue / violet / gold palette, refined robot avatars, SVG circuit traces between chambers, sparkline-driven stat cards, EKG-style system health

Open: `v2-claude-code-hub/index.html`

## Keyboard shortcuts (both)

- `D` — trigger "deployed" burst overlay + toast
- `Esc` — close agent drawer (v2)

## Stack

Plain HTML/CSS/JS. Google Fonts (Orbitron / Space Grotesk / Inter / JetBrains Mono / Press Start 2P / Rajdhani / Share Tech Mono) loaded from CDN.
